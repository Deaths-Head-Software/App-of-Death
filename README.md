 App of Death is a PyQt6 desktop application for Linux that provides a graphical interface for converting between the three major Linux package formats — .deb (Debian/Ubuntu), .rpm (Red Hat/Fedora/SUSE), and .pkg.tar.zst (Arch/Pacman). It wraps command-line tools like alien, debtap, and dpkg-deb behind a point-and-click GUI with automatic format detection, live conversion logging, and manual fallback extraction when the preferred tools aren’t available. Six conversion directions are supported: any format to any other.
